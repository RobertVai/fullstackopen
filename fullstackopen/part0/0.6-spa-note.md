# Exercise 0.6 — New Note in SPA

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note over browser: User writes a note and clicks Save

    Note over browser: JavaScript prevents default form submission
    Note over browser: Create note with content and date
    Note over browser: Add new note to local notes array
    Note over browser: Update the displayed notes

    browser->>server: POST /exampleapp/new_note_spa (JSON)
    Note over server: Save the new note
    server-->>browser: HTTP 201 Created

    Note over browser: Page stays open without reloading
```
