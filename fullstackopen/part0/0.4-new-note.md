# Exercise 0.4 — New Note Diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note over browser: User writes a note and clicks Save

    browser->>server: POST /exampleapp/new_note
    Note over server: Save the new note
    server-->>browser: HTTP 302 Redirect to /notes

    browser->>server: GET /exampleapp/notes
    server-->>browser: HTML document

    browser->>server: GET /exampleapp/main.css
    server-->>browser: CSS file

    browser->>server: GET /exampleapp/main.js
    server-->>browser: JavaScript file

    Note over browser: JavaScript executes

    browser->>server: GET /exampleapp/data.json
    server-->>browser: JSON with updated notes

    Note over browser: Render the updated notes
```
